# CrossOver 26.3.0 — open questions after the Phase 1 REA pass

Consolidated from the per-report unknowns (`signing.md` U-S*, `inventory.md` U-I*, `wine-fork.md` "Unknowns",
`evidence/sources-pass-26.3.0.json` U-SRC-*, and the `unknown` rows of the text-tooling pass). IDs `U-n` are the
ones `ledger.md` and `decisions.md` cite. Status: **open** (nothing in the static pass can answer it),
**partly resolved** (narrowed by this pass, still inferred), **resolved** (answered by a later pass; kept for the
record so the old ID still means something). Verification pass (2026-10-13): U-7 and U-13 moved to resolved,
U-20 narrowed to the strategy-B ABI question and marked blocking, U-SRC-1's evidence ID corrected.

Authority needed: `runtime` = would need execution of the CrossOver trial (EULA-permitted use, plan Phase 1 step
10, authority *controlled-replay*, kept separate from shipped-artifact rows); `out-of-scope` = would need
decompiling a proprietary/Apple file or the GUI/.pyc tooling (never); `external` = needs an artifact that is
not in the scratchpad (upstream tarball, DXMT release tarball, bootstrap engine); `source-read` = answerable by
reading the LGPL tree, just not done yet.
